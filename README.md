# alpha55
Alpha 55 - Logistics Professionals

Proof-of-concept marketing site for Alpha55 Transport — all-electric express LTL shipping out of Oregon, Ohio.

Plain HTML/CSS/JS, no build step. Open `index.html` in a browser to view.

```
index.html          single-page site
css/styles.css      styles (palette pulled from the logo: black, red #d71920, chrome silver)
js/main.js          mobile nav, scroll reveals, stat counters, quote form
assets/             logo
```

The quote form has no backend yet: on submit it opens the visitor's email app with a pre-filled message to craig@alpha55transport.com. Swap in a form service (Formspree, Netlify Forms, etc.) or a small API when going live.
